# Coffee Exploration Project

## Overview

This project explores three coffee datasets using Python and Pandas.

## Datasets

- Coffee Export
- Coffee Import
- Coffee Production

## Objectives

1. Load and inspect the datasets.
2. Identify rows, columns, and data types.
3. Check for missing values and duplicates.
4. Calculate descriptive statistics.
5. Evaluate data quality and identify business insights.

## Tools

- Python
- Pandas
- Jupyter Notebook
- GitHub

## Findings

The analysis will compare coffee exports, imports, and production across countries and years. Final findings will be added after running the code.
